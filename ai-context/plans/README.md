# Plans

Task breakdowns for a phase or slice of work, written before the work starts.

- One file per phase/slice: `phase-1-<topic>.md` or `<topic>.md`.
- Each starts with a status line — `> **Status: not started | in progress | done (YYYY-MM-DD).**`
  — and notes that `progress.md` is the authoritative record.
- Each states its **exit criterion**, the normative docs it implements, and numbered tasks with
  **acceptance criteria**. Estimates go beside tasks; actual effort is logged in `progress.md`.
- A plan that turns out wrong is corrected in place, with the correction noted in `progress.md`.
- Superseded plans stay, with a status line saying what replaced them.
